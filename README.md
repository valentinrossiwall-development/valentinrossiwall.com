# Valentin Rossiwall Personal Website

NDA-sichere statische Website.

## Vor Launch
- echte Domain in sitemap.xml / robots.txt eintragen
- Impressum und Datenschutz vollständig ergänzen
- öffentliches Kontakt-E-Mail festlegen
- echtes Portrait und Medien-Assets ergänzen
- öffentliche Links zu Buch, Artikeln, Videos, GitHub und Vorträgen ergänzen
- finale Prüfung aller historischen Rollen und Zeiträume gegen Primärnachweise

## Blog
Die HTML-Dateien unter `insights/` sind als SEO-fähige Startstruktur angelegt. Für echtes Self-Publishing sollte später ein CMS (z. B. Supabase/Lovable, Sanity, Ghost oder Decap CMS) angebunden werden.
